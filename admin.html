Ritmo de ingreso por hora

Dar códigos

Cada código es para una persona y queda a nombre del promotor. Se pasan tal cual o como link (/?c=CODIGO), que abre el formulario con el código puesto.
Promotor Códigos dados QRs sacados Sin usar Ingresaron Antes 11 Después · pagó Después · gratis Asistencia Activo
"QRs sacados" = personas que canjearon un código del promotor. "Ingresaron" cuenta a todos los que entraron, antes o después de las 11 (pagando o gratis, según lo que marcó la puerta). "Asistencia" = ingresaron / QRs sacados. Desactivar un promotor no borra sus entradas ya emitidas.

Generar códigos

Cada código sirve para una sola persona y queda atribuido al promotor. El link directo (/?c=CODIGO) abre el formulario con el código ya puesto.
CódigoPromotorCreadoEstadoCanjeado porAcciones
Revocar un código libre lo deja inservible. Un código ya canjeado no se revoca: para invalidar esa entrada, anula el ticket desde la pestaña Tickets.
